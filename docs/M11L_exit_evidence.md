## 5. Residuals (accepted for M11-lite, none touches the decision path)
1. **Production is rules-only for R6 (D-480).** Every card and the health line read "not available tonight" / "pending production" until the Owner wires a live router after the R6 bake-off. The whole path is mock-proven only.
2. **LLM-074 token estimate.** The reservation uses an estimate of author plus worst-case critic tokens, not a measured count (WP4 review).
3. **Partial persist.** A crash between the points and the night row leaves a written subject with no night row; the next run resumes without paying twice (D-507), but the night counters of the crashed run are lost.
4. **Critic unavailable is not logged as a call.** `critic_unavailable` is counted on `steelman_night` (`not_written_critic`) but there is no `llm_call` row for a critic that was never called.
5. **`signals.mjs` failure path is not unit-tested.** The try/catch around the bundle (D-504) is covered by reading and by the CLI tests, not by a test that breaks the bundle build.
6. **Errors fold into `no_model`.** An unexpected error is counted under `not_written_no_model` and reads "no model was available" (D-503a, D-560).
7. **Cut subjects show nothing (D-560).** A subject beyond `steelman_daily_cards` has no pack and the card draws no section; the `daily_limit` text is reachable only on a re-run after a cap change. Follow-up candidate: a zero-item pack row for a cut subject.
8. **No Editor/Viewer card e2e.** Masking is proven by the loader and UI tests (`leaks()` empty); the browser walk for those roles is not written.
9. **Shared reader files.** The reverse guard lists eight reader files (D-583); a new reader of the steelman must be added there on purpose.
10. **Open items of the design not built here:** reflections (WP8, D-496) and the monthly "Unproven notes" section; Committee, R7, VAL-111, `committee_*` are M12. So the "reflection part" of AT-32 and the "reflections queued" clause of AT-37 have nothing to test yet: `pick_reflection` exists, stays empty, and is inside the boundary (write allowlist, reverse guard, D-583).
11. **AT-32 runs the stage in-process.** The replay calls `steelmanNight` from the `runNights` hook with the mock routers, not the `scripts/arena/signals.mjs` bundle chain; the bundle path is proven by the AT-37 CLI tests (exit 0, `degraded`, no order or card changed) and by reading, not by the hash (with residual 5).
12. **Wallclock columns are outside the hash** (D-586): `schema_migrations.applied_at`, `source_register_history.changed_at`, `cortex_night.runtime_ms`. Nothing the steelman does can reach them, but a reviewer should know the three are not compared.
13. **The health line shows to every role.** `HealthModel.steelman` carries counts and fixed words only (no code, name or date), so it is not masked; if a later change adds a code to it, the loader must mask it (D-580).
