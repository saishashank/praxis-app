## 1. Scope

Back-end fixes (ch.10 V2 section 10.V2.1):

- GL-01 a price-only inferred split or consolidation is never auto-applied; vendor split/dividend records and Yahoo adjusted close veto it.
- GL-02 corporate actions carry `known_at`; replays use only factors known at the decision cut-off.
- GL-03 entry quantity is recomputed from the actual open (largest affordable whole parcel, at least one marketable parcel); cancel "cash" only when one marketable parcel is unaffordable; same rule in replay.
- GL-04 `adj_close` is optional and checked only when present.
- GL-05 batch 2b waits for the "first completed poll after 18:10" marker (enable slot `decision-cutoff`); backfilled rows store `first_ingested_at`.
- GL-06 a `dispatch-failed` run record with HTTP 401/403 raises an S2 incident the same night.
- GL-07 the watchdog workflow gets its own schedule lines (both DST offsets); approved by O-52, including the Batch-1 fallback schedule.
- GL-08 Evening Review footer adds the SEC-016 sentence ("Praxis never asks for keys or passwords").
- GL-09 the release gate fails when a mandatory check (ZAP baseline, real fixtures) was skipped rather than run.
- GL-10 dividends: arena trades credit cash dividends (O-51); correct the M8 register; comparisons use a total-return benchmark (DAT-235, ARN-095/103).

## 5. Open points and recommended defaults

1. **Missing ch.16 artefacts.** `docs/27_ui/mockup.html`, `01_reference_sites.md`, `02_page_audit.md`, `03_palette.md` and `walks/` are not in this repo (the data repo is not copied here, SEC-110; the brand files are the only allowed copy). Default: create `docs/27_ui/03_palette.md` and `docs/27_ui/walks/` in this repo as build artefacts (they contain no private data); generate the tokens from the palette file; skip the mockup recolour and run walks on staging.
2. **Hue and gradient values.** UXR-051 names hues but gives no hex values. Default: derive from the existing brand tokens (line #8FD3FF to #A7B4FF, signal teal #2DB5A3), keep gain/loss teal/orange (UXN-001), run `contrast-check.mjs` and a colour-blind simulation, fail the build on AA breaks.
3. **D-170 versus UXR-009 / UXR-012.** D-170 already widened pages to 1,760 px and uses shadows and glow at Owner request. Default: keep D-170 (Owner's later words win); update UXR-009 and UXR-012 wording in the decision.
4. **Config page.** UXR-028 wants edit drawers; D-174 made Configuration read-only because changes go through reviewed code. Default: keep read-only (list, current value, default, "changed" dot), no editor.
5. **Settings sheets versus `<details>`.** UXR-043 wants a sheet/drawer; D-171 used native `<details>` for no-JS support. Default: use the Sheet component (Radix dialog is already a dependency, D-164) with a no-JS fallback link to the detail page.
