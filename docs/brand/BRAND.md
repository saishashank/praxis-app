# Praxis — brand kit (v1, 2026-10-01)

**Name:** Praxis (O-39) · **Tagline:** *Learn. Earn. Repeat.* (chosen 2026-10-01; replaced T1) · **Mark:** "Signal P" (L9) — a price line that runs flat, jumps on news and curls into the bowl of a P; the dot is today's signal.

## Files
| File | Use |
|---|---|
| `praxis-logo-dark.svg/.png` | Header logo on dark themes (Dark, Midnight, Dim, High contrast) |
| `praxis-logo-light.svg/.png` | Header logo on the Light theme and white pages |
| `praxis-logo-tagline-dark/light.svg/.png` | Sign-in screen, About page, README |
| `praxis-mark-dark/light.svg/.png` | Mark only (narrow headers, loading screen) |
| `praxis-app-icon.svg` + `-1024/-512/-192/-180.png` | PWA / home-screen icons (192, 512), Apple touch icon (180), store-size master (1024) |
| `favicon.svg`, `favicon-32.png`, `favicon-16.png` | Browser tab (bolder stroke for small sizes) |
| `praxis-email-header.svg/.png` | Evening Review / reminder email header (600 × 120, shown at 1200 × 240 for sharp screens; light, because emails keep the light layout) |

SVGs are vector (any size). Text in the SVGs is converted to outlines, so no font needs to be installed. Prefer the SVG in the app; use PNGs where SVG isn't supported (email, app icons).

## Type
Wordmark: Inter Display SemiBold, −2% tracking. Tagline and UI: Inter (OFL licence — list in Settings → About, UXN-019).

## Rules
- Keep clear space around the logo equal to the height of the dot × 2.
- Don't recolour the line red/green, stretch it, or put the dark-theme logo on white.
- Minimum size: mark 16 px (use the favicon files), full logo 96 px wide.
- Personal, private app: "Praxis" is used by other businesses; a trademark search is needed only if the app ever becomes public.
