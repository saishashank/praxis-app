## Shape

- **Nothing goes live by itself.** Production keeps `llm_live_roles = []` at the merge. One factory (`src/lib/llm/factory.ts`, D-1401) is the only code that may build a live provider for the night; it fails closed to the existing rules-only router (`src/lib/llm/router.ts:242-246`) on any missing condition. The bake-off is the only door, and the Owner opens it after a PASS.
- **Every new model call uses the one router unchanged.** Budget (`router.ts:289-301`), injection filter (`:200`), datamarking (`:115-121`), schema with one repair (`:306-358`), grounding (`:342-346`) and the call log apply to the Committee, reflections, words, expert triage and extraction, and Workers AI alike. New budget buckets fit inside the unchanged 240,000-token daily total (D-1410).
- **Opinions stay opinions (PRD-033, D-930).** Committee ratings, reflections, MiniLM readings, alt-input regime readings and call proposals are written to their own tables, which the AT-32 complement proof excludes by name and a reader test keeps away from every trading, sizing, breaker and rule-version writer (D-1426, D-1447).
- **AU byte-identical, IN and US off.** No family rule version changes (the grammar addition is schema v2 for expert rules only, D-1436); the Worker slot table gains no slot, so the expert jobs ride on the existing nightly `maintenance.yml` dispatch (D-1429); every market-keyed 0039 table gets the guard triggers (D-1444).
- **One migration, first.** `0039_m22_llm_experts.sql` (task A1) creates every new table before any stream writes; schema pins move from 38 to 39 in the same task.
- **Measurements are pre-registered with one look (BLD-051).** Bake-offs (D-1405), the Committee trial (D-1420, D-1421), the alt-input regime test (D-1440) and the MiniLM comparison (D-1416) fix their hypothesis, split, n and hash before any computation and record their single look in `holdout_look` (`db/migrations/main/0036_m20_markets_data.sql:163-169`).
- **Private data stays private (SEC-110).** Per-expert licence results, cluster rule expressions and seed call proposals are produced into the private seed folder and imported by the Owner; the public repo gets counts, K-ids and outcome categories only (D-1431, D-1435, D-1437).
