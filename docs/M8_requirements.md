## 1. M8 scope (ch.12 §12.3, verbatim)

> M8 | AU go-live | Staging E2E day, security tests, restore test, bake-off, **rotation of every production token and revocation of the build-agent PAT (SEC-108 c)**, Owner walkthrough and sign-off | AT-28…AT-31 + all previous (s14)

Related items:

- **Chapter 14 rule** (`14` l.3): "The system is "done" for AU go-live when AT-01…AT-31 pass, each in the home environment named by **TST-115** (the single source), **before trading starts**." Also: "Results are stored as a test report in the repo (BLD-040)."
- **Chapter 14 acceptance** (`14` l.83): "**Given** a go-live request, **when** any AT-01…AT-31 is failing, **then** production go-live does not proceed."
- **Chapter 12 acceptance** (`12` l.88–89): "**Given** any milestone is declared done, **then** its exit tests in Ch. 14 pass in the home environment named by TST-115 and the result is in the build digest." and "**Given** M0 is incomplete, **then** no production deployment happens other than the bootstrap release (BLD-011)…".
- **Review point** (D-022, `docs/07_decision_log.md` l.28): the third review point is "Build complete:" at M8. Migrations main 0007 to 0011 and auth 0004 to 0006 "are not applied anywhere" until then (`docs/M7_exit_evidence.md` l.71).
- **After M8** (BLD-030, `12` l.68): live paper trading starts "the next AU trading day after M8 sign-off".
- **Release gate change** (TST-112, `10` l.151): the "Full release gate (from M8)" replaces the infrastructure release gate used in M1 to M7.
