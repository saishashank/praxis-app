## Shape

- **One gate for every look.** `src/lib/research/registry.ts` (task A2) is the only code that writes `holdout_look`: it needs a frozen pre-registration row with the same hash, takes the look once, and on a second attempt writes a refusal row and an Owner-visible log line instead (D-1602…D-1605). The three M20–M22 writers move onto it; offline looks reach it through a committed, append-only ledger file that the night imports (D-1606, D-1607).
- **Pre-registration is in this document.** Every hypothesis, grid point, split, n floor and PASS rule of M23 is fixed in the Decisions below, before any computation; each builder transcribes its item into a frozen JSON file under `docs/research/prereg/`, whose sha256 is the registry hash, committed before the code that computes the result runs (D-1610).
- **INCONCLUSIVE never spends a look.** Whether n is met is counted on entries alone, before any outcome is read; a short item is reported INCONCLUSIVE with its pre-registration frozen, and its one look stays available to the automatic evaluation that runs when n arrives (D-1605).
- **Monitors and meters read, never decide.** The eight residual monitors and the forward meters write only their own rows and Owner items; no family status, weight, threshold, rule version, book or order is touched; a PASS is recorded for the CTX-053 path, which stays a later reviewed step (D-1614, D-1623).
- **AU byte-identical, IN and US off.** Every new step runs after the Cortex night inside `o.replay !== true` and a try/catch (the movers pattern, `src/lib/cortex/stage.ts:1445,1483`), per enabled market only; every new table is market-keyed and guarded, and an AT-32 complement proof names them (D-1612, D-1645).
- **One migration, first.** `0040_m23_research.sql` (task A1) creates every new table and the two registry triggers; schema pins move from 39 to 40 in the same task.
- **History stays on the build machine.** CXA-003 and CXA-009 run there through `scripts/research/run-lineage.mjs --history <folder>`; only aggregates, hashes and verdicts are committed (D-1629).
- **Plan to 8 build days of a 10-day box**, three lanes, with a cut list that turns the least valuable research items into INCONCLUSIVE reports first (D-1601, D-1644).
