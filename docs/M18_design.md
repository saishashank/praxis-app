### SEC-115 HMAC signature covers method and path **F**
- **Current state (verified).** `src/lib/security/hmacCore.mjs:12-14` `hmacMessage(timestamp, nonce, rawBody)` = `${timestamp}.${nonce}.${rawBody}`; no method, path or version. Verifier `src/lib/security/hmac.ts:33-80` (`computeSignature`, `verifySignedRequest`). Signers: Node `scripts/smoke/sign.mjs:9` (used by `scripts/backup/run.mjs`, `scripts/maintenance/run.mjs`, `scripts/e2e/test-login.mjs`, `scripts/watchdog/run.mjs`, `scripts/smoke/stage2.mjs`); Worker `worker/src/selfcheck.ts:106-127` `signHeaders(secret, body, ts, nonce)` used by `worker/src/asx/sentinel.ts:137,262`, `worker/src/asx/universe.ts:212`, `worker/src/routes.ts:175`. Verifiers (10 handlers): `src/app/api/test-identity/login/handler.ts`, `src/lib/alerts/machine.ts`, `src/lib/backup/exportHandler.ts`, `src/lib/data/universe/handler.ts`, `src/lib/maintenance/handler.ts`, `src/lib/review/routeHandler.ts`, `src/lib/selfcheck/handler.ts`, `src/lib/sentinel/handler.ts`, `src/lib/workerReport/handler.ts` (+ `src/lib/auth/testIdentity.ts`). - **Design.** D-957. `hmacCore.mjs` exports `HMAC_SCHEME_VERSION = 2`, `HEADER_VERSION = "x-praxis-version"`, `hmacMessage({ method, path, timestamp, nonce, bodySha256Hex })` = `v2\n${METHOD}\n${path}\n${timestamp}\n${nonce}\n${bodySha256Hex}` (method upper-case; `path` = URL pathname only, no query, no host; body hash = SHA-256 hex of the raw body bytes, computed per runtime). `signedHeaders` adds `X-Praxis-Version: 2`. The verifier takes `method` and `path` from the request (`req.method`, `new URL(req.url).pathname`), refuses any version header other than "2" **before** the signature compare (401, nonce not claimed), and keeps the order of D-029 (secret → headers → skew → compare → claim). `verifySignedRequest` gains required `method` and `path` args, so every handler fails to type-check until updated (the compiler finds the 10 call sites). The Worker signer takes `(secret, { method, path, body, ts, nonce })`; the three Worker callers pass the route path they post to. `scripts/smoke/README.md` and the `hmac.ts` header comment document v2; the three known-answer tests share one new literal; a new test proves a v1-signed request (old literal) is refused with 401 and claims no nonce; `tests/auth/testIdentity.test.ts` and `scripts/smoke/stage2.test.mjs` use the new signer. `hmac_scheme_version` is registered in `src/lib/config/keys.ts` as a fixed key whose default is the exported constant (validate `never`), so the Configuration page shows it (ch. 15 §15.11.5) without a second definition (D-979).
- **Deploy note (listed in the PR).** The verifier refuses v1 the moment Vercel is live; the Worker deploys in the same `deploy-production` run, so the window is the minutes between the two deploy steps. Smoke stage 2 (`scripts/smoke/stage2.mjs`) proves both signed paths after the deploy; the Owner runs it once (already an Owner step).
- **Tests first.** The known-answer literal and the refusal test are written before the scheme changes. **AT-83** ("HMAC v2 refuses an old signer and both signed paths pass smoke stage 2"). **F** (Fable reviews every line of `hmacCore.mjs`, `hmac.ts`, `selfcheck.ts` and the handler diffs).
