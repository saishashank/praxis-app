## Private dry runs (counts only, SEC-110, D-1431)

Run on 2026-11-17 against the private seed outside the repository (the seed folder holds the format-1 manifest and the five files; no name, handle, URL or path is recorded here or anywhere in the repository):

- **Licence first check** (`scripts/experts/licence-check.mjs --seed`): 100 experts, all `tracked` and tier `core`; none carries a handle or a home address, so the check found **0 sources, 0 checked, 0 not fetched and made 0 requests** (the seed names no feed address; 12 experts are marked "no feed"). It wrote `licence-check.json` (empty results) beside the seed. The first check therefore needs source addresses added to the seed by the Owner (exit evidence, section 8).
- **Call proposals** (`call-proposals.mjs --seed --dry-run`): **28 call claims, 0 complete, 23 incomplete** (missing: code 23, direction 15, date 21, horizon 23) and **5 not trackable**; 0 already structured (no `calls.json`). Nothing written.
- **Cluster expressions** (`express-check.mjs --seed`): could not run, because the seed has no `expressions.json` and the manifest is format 1 (the script says so). The seed's 60 clusters are 3 with a family fit and **57 parked**; all 57 are "not yet addressed" until the Owner supplies the expressions, so the target of 20 expressed is not met yet; it is reported, not forced (D-1437).
- **Importer dry run** (`import.mjs <seed> --dry-run`, run with the empty `licence-check.json` set aside, because a format-1 seed refuses that file): 100 experts, 23 red flags, 275 items, 60 clusters, 347 claims, 976 claim-item links, 375 claim-cluster links, 0 calls; nothing written.
