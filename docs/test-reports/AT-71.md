# AT-71 Switch-on and rollback (M20)

Reference: V3 spec ch. 20 (MKT-111, MKT-113, UXN-312), ch. 14 (AT-71). Decisions D-1099 to D-1101, D-1105, D-1107, D-1124, D-1129, D-1130, D-1146 and D-1190 to D-1199 in [M20_design.md](../M20_design.md). The requirement text lives there; this file does not restate it.

## Home environment (TST-115)

Local run on the Windows build machine (vitest and node:test), real migrated libSQL files (migrations 0034 to 0036), the Worker's SQLite double, no network. The Owner performs the switch after the merge; nothing in the build sets `markets_enabled`, `market.enabled` or `PRAXIS_MARKETS_ENABLED` in production (BLD-050). The IN and US `data_only` recorded days run in CI only (job `recorded-day-dev`).
