## Home environment (TST-115)

Local run on the Windows build machine (vitest and node:test), real migrated libSQL files (migrations 0034 and 0035), the Worker's SQLite double, no network. The production shape is the migration seed: AU enabled, IN and US built, disabled, mode `off`. The proofs run on every CI push: root suite and `worker` job, the empty e2e lane, and the last functional step of the `recorded-day` job. The e2e walk and the recorded-day step run in CI only: see the PR head.
