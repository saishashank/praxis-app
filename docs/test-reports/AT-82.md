## Known limits

- The walk rotates the six themes over the pages (D-1327) instead of crossing every page with every theme; the per-theme checks live in the vibrancy, theme-emulation and contrast specs.
- The walk does not read the page text of the Blueprint (a spec browser that shows requirement and decision ids on purpose) and leaves out the steelman's evidence markers (D-1328).
- A rendered string that no source scan can see (text built from stored data, for example an id inside an AI-written point) is checked only on the pages the walk opens.
- Pinned AU e-mail wording ("Praxis P0:", "of NAV") stays, allow-listed with its reason.

Nothing in this file claims a result that has not happened.
