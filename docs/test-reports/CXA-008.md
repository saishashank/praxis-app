# CXA-008 Text labels: agreement and paraphrase check
Item: CXA-008 (ch. 22) · Lineage: text_label_guidance, text_label_event_confirm, text_label_tone · Market: AU · Status: INCONCLUSIVE

## Hypothesis
A machine label read from an announcement (what it says about guidance, whether it confirms an event, its tone) agrees with the Owner's own reading of the same item, is stable under a neutral rewording and flips under a tone-flipping one, and ranks the 20-session market-adjusted outcome within each sign stratum of the announcement-day move. A pass would only allow the label into the sentiment cluster through the Owner-run passport import.
