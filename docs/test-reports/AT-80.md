## No live bake-off was run (D-1534)

The live bake-off of the Groq candidates was **not dispatched** in the build: it would run on the production commit, which lacks the V3 harness, and it writes to the live database. So **no PASS exists for any role and every role is rules-only**, and **0 provider requests are made with every key present and no role live** (the first row below). Dispatching `llm-bakeoff.yml` on `release` and writing the index is an Owner step after the merge (exit evidence, section 8). The bake-off index (`src/lib/llm/bakeoffIndex.generated.ts`) holds no PASS row; the words and Committee-judge rows read "not run live".
