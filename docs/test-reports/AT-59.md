## Known limits

- Edge hover is exercised in one view (Platform); the keyboard reaches an edge through the open node's connection buttons, not as a tab stop (D-1321); node hover is exercised on the first node of the Platform view, not on every node of every view.
- 22 of 136 Platform edges are fully covered by other drawing and cannot be hovered with a mouse.
- Pinch/drag on a real touch device is not tested; the zoom button changes the same transform.
