## Known limits

- D-371: anonymous `/blueprint*` gets the ordinary sign-in redirect and `/api/blueprint*` the ordinary 401, not a 404 (the "indistinguishable" clause wins). This amends the ch. 18 wording; listed for the Owner.
- D-377: a signed-in editor or viewer can tell `/blueprint` from a missing route by crafting an `RSC: 1` request (the `x-nextjs-rewritten-path` header). The e2e test asserts this exact residual. Anonymous and plain page requests show nothing.
- The walk covers pages that render without a seeded row (`concretePath`); registry entries that need a row are skipped in the empty scenario.

Nothing in this file claims a result that has not happened.
