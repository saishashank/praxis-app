# AT-73 Opinions and proposals have no path to trading (M22 part)

Reference: V3 spec ch. 14 (AT-73), AGT-145, AGT-148, KB-084. Decisions D-1427, D-1447, D-1469, D-1519, D-1520 and D-1535 in [M22_design.md](../M22_design.md). This file is the **M22 part** (the shared clauses for call proposals and the opinion boundary); M23 adds the angle proposals to the same acceptance file (`at73Shared.test.ts`, D-1447). The requirement text lives in the design; this file does not restate it.

## Home environment (TST-115)

Local run on the Windows build machine (shared), Vitest, real migrated libSQL files (migration 0039), the 20-fixture call-proposal set, source-level boundary tests, no network, no model.
