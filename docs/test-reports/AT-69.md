# AT-69 India rules in development mode (M20, IN1)

Reference: V3 spec ch. 14 (AT-69), ch. 20 (DAT-243 to DAT-247, ARN-116 to ARN-118). Decisions D-1102, D-1104, D-1108, D-1109, D-1113, D-1132, D-1154, D-1163, D-1169 and D-1170 to D-1179 in [M20_design.md](../M20_design.md). The requirement text lives there; this file does not repeat it. India is built and OFF in production (`markets_enabled` stays `["AU"]`, AT-68): every test below runs in a throwaway development database with IN enabled by `allowMarket`, no network (SEC-110).

## Home environment (TST-115)

Local runs on the Windows build machine (vitest, node environment, `node --test` for the scripts), throwaway libSQL files. The fixture sessions are hand-made files in the exchange's own field names (`tests/markets/in/dayFixture.ts`) and, where the private fixtures checkout is present, the five recorded sessions 2026-11-05 to 2026-11-12 of `praxis-app-fixtures/recorded/IN/` (D-1177).

## Not claimed

- The Nifty 50 and India VIX series are not in the extract; the clause is proven on the readers and the "unmeasured" behaviour, not on a measured regime table (D-1173).
- Index-relative angles are unmeasured for India until a series exists; the calibration was not run (`docs/cortex/calibration-IN.md`, D-1179).
- India macro rows are parsed, not stored (D-1171).
