## Shape

- **Everything Phase R is off and invisible by default (PRD-041, D-931).** `owner_real_money_tools = "off"` in a fresh configuration; `/recommendations`, `/holdings`, `/trades` and their actions and routes answer exactly what a missing route answers, for every role, while it is off, and for Editors and Viewers while it is on (AT-77). - **Nothing M21 adds can move a book, order, signal, rule or alert (AT-32 boundary).** Owner-typed rows (trades, holdings, labels, capital, broker templates) live in tables or preferences that no trading, learning or Cortex module reads (a reader test, D-1221); the shadow short stream writes only its own two tables and nothing else, not even a log line on success (D-1228); the target exit is a challenger-only rule key that no seed rule carries (D-1224). - **AU byte-identical, IN and US off.** Every new market-keyed table gets the 0035 guard triggers in its own migration (D-1022 pattern; `scripts/db/gen-market-guard.mjs`); production `markets_enabled` stays `["AU"]` (AT-68 every CI run); the per-market facts M21 needs (financial-year start, short-sale rules) live under `src/lib/market/seed/` (AT-67 at 0).

- **Plain words (D-884, D-919, D-922).** Every new text an Owner reads passes the new D-922 scan (D-1233), and the AT-82 walk checks rendered page text for internal codes.
- **$0, Turso ≤ 20 %, no OFFSET, no staging, ASX Worker off, no secrets.** No new provider; every new statement is a key probe or a bounded keyset read with a `rows-ok:` comment; the proxy reads the Owner switch through the 60 s config cache (D-1215); `worker/` is not edited; the PWA adds a static manifest and a same-origin service worker only (D-1231); broker links carry no credentials and the server never calls a broker host (D-1218).
