# Build Specification — Read Me & Progress Tracker

_Started 2026-09-21 (session 4). This folder is the **authoritative, build-ready requirements document** for the Investment AI web app. It is written progressively, chapter by chapter, and is meant to be handed to an AI build agent to implement end to end. **It contains no code by design.** The research and rationale behind it live in `../docs/` (files 01–13); **if `spec/` and `docs/` disagree, `spec/` wins.**_

## 0. Precedence (updated session 9, v1.1)
Authority when texts disagree: **owner decisions (O-n, §3) → chapters 01–12, 14 and 15 → chapter 13 (history) → `docs/project_imports/`** (REV-001). Within chapters 01–15: (a) for a given requirement ID, its **home chapter** wins; (b) text marked **(s9)** wins over older wording; (c) chapters 05–12, 14, 15 win over 01–04 on overlapping subjects. IDs are stable across moves.
- **REV-003** Any performance figure (win rate, CAGR, confidence %, uptime, data quality, test coverage, line counts) in any document without a stored measurement behind it is void; the system shows "not yet measured" until it computes the value from its own data.

_Handoff package:_ the spec (ch. 00–15, with ch. 13 as history) is committed to the **public** code repo and contains no personal data (SEC-110 e); `docs/` (decision log, questions, reviews), `log/`, `RESUME.md` and `docs/project_imports/` are **private** — they stay in the Owner's folder / Claude Project and may be copied to the private data repo, never to the code repo; references to FIX-/REV- items and `docs/14` resolve there, but every MUST that a build needs is stated in ch. 01–12, 14–15.

## 1. How a build agent must use this spec
1. Read this file, then chapters 01–12, 14, 15 and 16 in numeric order; chapter 13 is history only. In ch. 16 every **P1** item is accepted and binding for v1 (O-38) and wins over ch. 09 where they differ; P2/P3 items are not built in v1. All chapters listed in §5 are in scope. **(s14)**
2. Requirement keywords follow RFC 2119: **MUST / MUST NOT / SHOULD / MAY**.
3. Every requirement has a stable ID (e.g. `PLT-014`). Cite IDs in commits, tests and status reports. Never renumber; mark superseded items instead.
4. Every chapter ends with **acceptance criteria** written as Given/When/Then statements. A chapter is "done" only when all its criteria pass.
5. Values marked **[VERIFY at build]** (free-tier limits, prices, model names) change without notice. The build agent MUST re-check the provider's live documentation/dashboard at build time and put such values in configuration, never hard-code them.
6. The build agent MUST NOT call any paid endpoint, add a payment card anywhere, or exceed a free quota knowingly (see PRD-007).
7. When the spec is silent, choose the simplest option that satisfies the $0, private, owner-controlled (roles per ROL-101) constraints and record the choice in `docs/07_decision_log.md`.
8. The build agent MUST keep the markdown knowledge base (see README protocol) current as it works.

## 2. Conventions
- **Praxis** = the name of the app (O-39). Every page title, the logo, the email sender name ("Praxis") and every email subject start with it (e.g. "Praxis · Evening Review · Mon 5 Oct", "Praxis: 1 item needs attention"). **Sentinel** = the market-watching agent; **Arena** = the set of paper portfolios.
- **Owner** = the person who owns the system (name and email are kept only in the private docs and in the `OWNER_EMAIL` environment variable, SEC-110 e). **Users** = the Owner plus any allowlisted Editors/Viewers (ROL-101…106). **System** = the web app plus its scheduled jobs and agents. **Market** = AU, IN or US (MKT-101).
- **Arena** = the set of parallel paper portfolios. **Portfolio** = one independent paper account starting with the seed capital.
- **Cohort** = one run of a portfolio from a start date until it reaches its target, busts, or times out.
- **TTD** = Time-To-Double (time-to-target): trading days (and calendar days) from cohort start until **liquidation NAV** (NAV minus estimated exit costs, Ch. 05 §5.1) first reaches 2× seed capital.
- **Bust** = liquidation NAV falls to or below the bust threshold (default 50% of seed); other terminal states (target, stalled, timeout) per Ch. 05 §5.1.
- Currency per market (AUD for Australia). AU seed **A$600**, target **A$1,200**, bust **A$300** (O-25). Timezone for all owner-facing times: **Australia/Melbourne** (handles daylight saving); storage in UTC.
- Tags: **[OWNER]** stated by owner; **[PROPOSED]** suggested default awaiting owner confirmation; **[VERIFY at build]**.
