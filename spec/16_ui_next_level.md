## 16.1 Design direction

One coherent visual language, dark-first (light theme available, UX-001):
- **One gain/loss colour pair**, chosen for colour-blind safety (deuteranopia/protanopia): **teal** for gains, **burnt-orange/amber-red** for losses — never plain red/green. Every gain/loss indicator MUST also carry the sign (+/−), an arrow icon (↑/↓) and, where relevant, a text label ("Gain"/"Loss") — colour is never the only signal (WCAG 2.2 AA).
- **Regime badges** (AGT-101: SHOCK / RISK-OFF / RISK-ON / NEUTRAL) and **validation labels** (ARN-086) each use their own neutral token family (e.g. slate/indigo for regime, grey→blue progression for validation) — never the gain/loss teal/orange pair, so a bad regime is never visually confused with a losing trade.
- **Thesis-breaker status** (AGT-111 green/amber/red) is a third, distinct token family (status, not gain/loss or regime).
- Tabular numerals for every number (price, NAV, %, n) so columns align; free Google-Fonts (OFL/Apache) only. _(s12 amendment: one sans family for all text incl. headings — see §16.24.)_
- Motion: purposeful only (loading, state change); `prefers-reduced-motion` disables all non-essential animation; no confetti, no streak/urgency motion, no auto-playing sound.
- Two density modes (comfortable/compact), user-selectable, persisted per UX-110 personal preferences.
